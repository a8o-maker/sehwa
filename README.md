# sehwa

모바일 청첩장 한 페이지.

- `index.html` — 단독 실행 가능한 한 파일. 외부 의존성은 Google Fonts뿐입니다.
- `p/01.jpg` … `p/06.jpg` — 표지·갤러리·맺음에 쓰는 사진.

## 구성

표지 사진(아치) → 이름·일시·장소 → 인사말과 라인 일러스트 → 축하 연락처 →
예식일(달력·남은 날짜 자동 계산) → 갤러리(라이트박스: 좌우 화살표·스와이프·ESC) →
오시는 길(약도 일러스트·교통편) → 축의금 계좌(복사 버튼) → 맺음.

## 실제 정보로 바꿀 곳

현재 이름·일시·장소·연락처·계좌는 모두 예시값입니다.

| 항목 | 위치 |
| --- | --- |
| 이름 | `.names`, `.parents`, 맺음말 서명, `.who-row`의 이름 |
| 예식 일시 | `.when`, `.bigdate`, 달력 표(`table.cal`), 스크립트의 `new Date(2026, 10, 1)` |
| 장소·약도 | `.place` 섹션과 `svg.map`의 텍스트 |
| 연락처 | `.who-row`의 `data-phone` 속성 |
| 계좌 | 스크립트의 `ACCOUNTS` 객체 |
| 사진 장수 | 스크립트의 `TOTAL` |

달력을 바꿀 때는 표의 시작 요일과 `.mark`(예식일 강조) 위치를 함께 맞춰야 합니다.

## 남은 작업
