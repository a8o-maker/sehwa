# sehwa

라인 일러스트로 만든 모바일 청첩장.

- `index.html` — 단독 실행 가능한 한 파일짜리 청첩장. 외부 의존성은 Google Fonts뿐이며, 브라우저에서 파일을 바로 열거나 정적 호스팅에 그대로 올리면 됩니다.

## 바꿔야 할 값

| 항목 | 위치 |
| --- | --- |
| 신랑·신부 이름 | `.names`, `.parents`, 맺음말 서명 |
| 예식 일시 | `.when`, `.bigdate`, 달력 표(`table.cal`), 스크립트의 `new Date(2026, 10, 14)` |
| 예식 장소·약도 | `.place` 섹션과 `svg.map`의 텍스트 |
| 연락처 | `.contact-row`의 `tel:` / `sms:` 링크 |
| 계좌번호 | `details.acct` 안의 텍스트와 각 버튼의 `data-copy` |

현재 들어 있는 이름·주소·연락처·계좌번호는 모두 예시값입니다.
